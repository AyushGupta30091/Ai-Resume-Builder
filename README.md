🚀 AI Resume Builder
A simple AI-powered web app that helps you create a clean and professional resume in just a few steps.
Instead of struggling with formatting and wording, you just fill in your details and let the tool help you build a better resume.


💡 What this project does
This project is made to make resume building easier and faster.
It guides you through your details (education, skills, experience, etc.) and helps you turn them into a proper resume format.
You can also preview your resume before downloading it.

✨ Features
Easy form to enter all your details
AI suggestions to improve your content 
Real-time resume preview
Clean and simple UI
Download resume as PDF
Works smoothly on both mobile and desktop

🛠️ Tech Stack
Frontend: React / HTML / CSS / JavaScript
Backend: Node.js / Express
Database: MongoDB
PDF Generation: jsPDF / html2pdf
AI: OpenAI API
